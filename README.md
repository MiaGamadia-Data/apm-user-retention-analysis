# APM User Retention Analysis 

## Overview
The project analyzes user behavior in a simulated fintech application to identify churn drivers and recommend product improvements

## Problem 
Users are dropping off during onboarding and not engaging with key features

## Approach 
- Analyzed user engagement metric (sessions, transactions)
- Evaluated churn patterns 
- Built onboarding funnel analysis 

## Key Insights
- Low session count is strongly correlated with churn 
- Users who do not complete onboarding are more likely to churn 
- Transaction activity is a strong indicator of retention 

## Product Recommendation 
- Simplify onboarding flow to reduce friction 
- Encourage early transactions through incentives 
- Add guidance or progress indicators during onboarding 

## Tools Used 
- Python (Pandas, Matplotlib)
- Jupyter Notebook
